# NAOTR-POS

## Enterprise POS and Inventory Management System

A Windows desktop application developed using C#,
Windows Forms, .NET Framework 4.8, and SQL Server.

## Features

- Login and role-based access control
- Dashboard and sales monitoring
- Inventory management
- Automatic SKU and barcode generation
- Category management
- Customer management
- Point of Sale
- Checkout and payment processing
- Receipt preview and printing
- Stock adjustment and inventory history
- Sales history and transaction voiding
- Sales reports and CSV export
- User management

## System Requirements

- Windows 10 or Windows 11
- .NET Framework 4.8
- Microsoft SQL Server Express
- SQL Server Management Studio

## Installation Instructions

1. Download the application ZIP from GitHub Releases.
2. Extract the ZIP file.
3. Open SQL Server Management Studio.
4. Connect to .\SQLEXPRESS.
5. Open and execute trocio.sql on a fresh database setup.
6. Keep the EXE and EXE.config files together.
7. Run the application executable.

## Database Configuration

Database Name: trocio
SQL Server Instance: .\SQLEXPRESS
Authentication: Windows Authentication

If your SQL Server instance is different, update
the connection string in the EXE.config file.
